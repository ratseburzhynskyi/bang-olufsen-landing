# Bang & Olufsen Landing Page

A responsive landing page inspired by Bang & Olufsen, a premium audio brand. The project focuses on clean design, elegant typography, product presentation, and responsive layouts.

## Demo

[View Live Demo](https://ratseburzhynskyi.github.io/bang-olufsen-landing/)

## About the Project

This project is a landing page created from a design mockup as a front-end development practice project.
The page presents Bang & Olufsen products and includes product recommendations, product categories, brand information, and a contact form.

## Features

- Responsive page layout
- Product showcase with descriptions and prices
- Product category section
- Navigation between page sections
- Contact form
- Clean and minimalist visual design

## Technologies Used

- HTML5
- SCSS (Sass)
- Gulp
- BEM methodology

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/ratseburzhynskyi/bang-olufsen-landing.git
   ```

2. Navigate to the project directory:

   ```bash
   cd bang-olufsen-landing
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```
